# claude-plugins

Claude Code plugins by Salman.

## Add this marketplace

```
/plugin marketplace add smian1/claude-plugins
```

Then install a plugin with `/plugin install <plugin>@smian1`, or browse them with `/plugin`.

## Plugins

| Plugin | What it does | Install |
|---|---|---|
| [imessage-history](plugins/imessage-history) | Search, export and analyze your local iMessage history: conversations, group chats, attachments and stats. macOS only, read-only | `/plugin install imessage-history@smian1` |

## Updates

Run `/plugin marketplace update smian1` to pick up new plugins and versions.
